# Security and privacy

The completed checklist is [SECURITY-CHECKLIST.md](../SECURITY-CHECKLIST.md), at
the repository root. It stays there, under that name, because that is where it
is graded from.

It covers secrets and credentials, GitHub Actions, the database, access
control, input and output, and repository privacy. Every row is answered Yes,
No or N/A with a line of evidence, and the last section lists what was found
and fixed along the way.
